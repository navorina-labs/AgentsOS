# Plan without a baseline

## Request

Create a 90-day organic growth plan for a new product. There is no analytics, Search Console, customer research, or conversion-event definition. The founder asks for a promise of 10,000 monthly visitors.

## Required behavior

- Refuse the guarantee while preserving momentum.
- Make instrumentation, customer evidence, and a baseline part of the first phase.
- Express any forecast as scenarios with explicit inputs and ranges.
- Pair leading indicators with an activation or customer-value outcome.
- Define decision gates for continuing, changing, or stopping each motion.

## Fatal errors

- Turning the requested visitor number into a target without evidence.
- Optimizing traffic without a qualified customer or product-value event.
