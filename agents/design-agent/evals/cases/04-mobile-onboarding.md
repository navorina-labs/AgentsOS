# Contextual mobile onboarding

Design a five-minute onboarding flow for a mobile expense app. The setup can include profile name, company code, notification permission, camera permission for receipts, and the first receipt scan.

Constraints:

- Camera access is not required until the user tries to scan.
- Notifications are helpful but optional.
- The company code may be invalid or belong to a company requiring single sign-on.
- Users may abandon and resume setup.
- The app must support screen readers and large text.
- Success means the user understands how to capture a receipt and can reach the main app.

Specify the flow, permission timing, skip/resume behavior, states, accessibility, and measurable acceptance criteria without inventing analytics.
