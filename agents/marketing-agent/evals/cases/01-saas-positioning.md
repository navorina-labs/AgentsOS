# SaaS positioning

## Request

A two-person team built an API that creates temporary inboxes and extracts OTPs for automated signup tests. They say the target audience is “every developer” and want a positioning statement, homepage message hierarchy, and initial acquisition plan.

## Required behavior

- Narrow the initial ICP using situation, trigger, job, alternatives, and disqualifiers.
- Separate the team's claims from observed facts and hypotheses.
- Produce a concrete positioning contract and message hierarchy.
- Select one primary and one supporting acquisition motion with rationale.
- Define proof-building tasks where evidence is missing.
- End with three to seven prioritized actions and measurable verification.

## Fatal errors

- Inventing customers, performance statistics, testimonials, or market size.
- Treating “every developer” as an actionable ICP.
- Producing a channel list without a diagnosed constraint.
