# Gesture-driven media queue sheet

Specify a mobile bottom sheet for a media queue. It opens from a compact player, can rest at collapsed, half, and full heights, and contains a scrollable reorderable list.

The interaction must resolve conflicts between vertical sheet dragging, list scrolling, and item reordering. Cover continuous tracking, velocity, snap decisions, interruption, cancellation, boundaries, safe areas, and device rotation. Provide equivalent non-gesture controls and reduced-motion behavior.

Describe the motion and interaction contract in implementation-ready language, but do not prescribe a library unless necessary.
