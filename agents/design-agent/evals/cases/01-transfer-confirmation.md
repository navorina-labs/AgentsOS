# Bank transfer confirmation

Design an implementation-ready responsive UI specification for the final review and confirmation step of a bank transfer.

Context:

- The user has already selected a recipient and entered an amount.
- Show recipient name, masked account number, amount, fee, total debit, execution date, and optional note.
- The transfer may fail because of insufficient funds, a daily limit, network loss, or an expired session.
- Desktop web and mobile web must use the same backend flow.
- A submitted transfer cannot be silently reversed.
- Do not assume access to research, analytics, or an existing design system.

Include the interaction contract, relevant states, responsive behavior, accessibility, and testable acceptance criteria. State consequential assumptions.
