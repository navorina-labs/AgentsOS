# Accessible permanent-delete dialog

Define the interaction contract for a dialog that permanently deletes a workspace and all of its projects.

The initiating page already contains a button labeled “Delete workspace.” Deletion can take up to 30 seconds and can fail. The workspace name may be long or contain non-Latin characters. Some users rely only on a keyboard or screen reader.

Specify anatomy, copy roles, focus entry and return, keyboard behavior, accessible semantics, pending/success/error states, prevention of accidental activation, and recovery expectations. Include concise acceptance criteria.
